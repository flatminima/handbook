# FlatMinima Value

1. **最適解の追求**：
   フラットミニマでは、すべての関係者に対して、最適解を見つけることを重視します。

2. **教育と貢献**：
   我々の使命は、教育を通じて沖縄および日本の発展に貢献することです。フラットミニマは、技術や知識を普及させることで社会への影響を拡大し、持続可能な成長を促進します。

3. **誠実と透明性**：
   私たちは、常に誠実で透明性のある取り組みを心がけます。信頼と誠実さが私たちの行動の基盤であり、オープンで正直なコミュニケーションを通じて、信頼関係を築きます。

4. **率直で責任ある対話**：
   フラットミニマでは、重要な意見や指摘を率直に行える場を提供します。全員が発言に責任を持ち、組織やプロジェクトの成功に貢献することを求めます。また、発言によって心理的な不安や恐怖を感じることなく、安心して意見交換ができる環境を作ります。
